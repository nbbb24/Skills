# Skill routing

This repository contains reusable skills at its top level. If they are absent
from the session's skill catalog, read the matching local `SKILL.md` directly.

- For repository PR/MR activity, recent changes, delivered capabilities, or
  in-progress work, use [pr-insights](pr-insights/SKILL.md). This includes informal
  requests such as “看一下过去三周 memfabric 的 PR 情况”, even when the user only
  supplies a repository URL and does not name the skill.
- For updating an existing README from verified PR outcomes, use
  [readme-sync-from-prs](readme-sync-from-prs/SKILL.md).

Match the requested task: reviewing or changing an individual PR does not call
for a repository-wide PR report. Announce the selected skill before using it.
